# Sahal & Ayesha — Wedding Invitation

A digital wedding invitation website featuring an interactive unsealing envelope, background music, countdown timer, event itineraries, RSVP form, wishes wall, and video backgrounds.

## Features
- **Cinematic Envelope Opening**: Interactive tap-to-open wax seal envelope animation.
- **Ambient Audio**: Built-in audio toggle with gentle fade-in and visual equalizer bars.
- **Live Countdown**: Animated rolling digits counting down to the wedding day.
- **RSVP & Wishes Wall**: Connected response system and guest book.
- **Responsive Layout**: Designed for mobile and desktop screens.

## Quick Start
You can view the site locally by opening `index.html` in any web browser, or serve it using any HTTP server:

```bash
# Python
python -m http.server 8080

# Node.js
npx serve
```
